Everything you need

Manage your entire Claude Code environment from a single tool.

Stacks

Bundle MCP servers, hooks, commands, agents, settings & fragments into one shareable config. Install entire environments in seconds.

Plugins

Full plugin ecosystem with Git integration. Install, update, enable/disable from any repository. Create your own with the interactive wizard.

Memory Fragments

Persistent context that survives sessions. Install team knowledge bases that integrate directly with CLAUDE.md.

Doctor

Built-in diagnostics. Run pacc doctor to detect and auto-fix configuration issues across your entire environment.

Team Sync

Share configurations via pacc.json. Lock versions with pacc.lock.yaml. Sync environments and onboard new devs in seconds.

Security

170+ threat patterns detected. 4-level sandbox isolation. SHA-256 verification. Lockfile pinning. Enterprise-grade protection.

Why PACC?

Stop copy-pasting configs. Start shipping.

Without PACC

  • Manually edit settings.json for each project
  • Copy MCP configs from Slack threads
  • Onboarding takes hours of "just copy my config"
  • Config drift between team members
  • No validation — broken configs discovered at runtime
  • No rollback when things break

With PACC

  • One command installs your entire environment
  • Stacks bundle everything into versioned packages
  • New devs run pacc sync and they're done
  • Lockfile ensures identical environments everywhere
  • pacc doctor catches issues before they bite
  • Timestamped backups + rollback on every operation

Command Reference

Familiar patterns. Powerful results.

CommandDescription
pacc stack install <repo>Install a stack from Git
pacc stack syncIdempotent sync to desired state
pacc stack export <name> <dir>Export config as a shareable stack
pacc doctorRun diagnostics with optional --fix
pacc plugin install <repo>Install plugin from Git
pacc plugin search <query>Search community plugins
pacc fragment install <src>Install memory fragments
pacc syncSync everything from pacc.json
pacc install <source>Install extensions from files/URLs
pacc validate <source>Validate without installing
